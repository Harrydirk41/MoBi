# MEDI524 - modeling task

You are given `report/` (physchem, in-vitro, clinical description) and `data/` (2 clinical studies as time,concentration CSVs). Extract the inputs, build the whole-body PBPK model, and fit the identifiable parameters. The reference model's methods and fitted values are withheld; your model is graded on how well it predicts held-out studies.
